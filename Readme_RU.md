# MediaExplorer 1.0.10 — музейный браузер для Windows 10 Mobile


![](/Images/logo.png)

## Что это?

MediaExplorer — это хобби-браузер для Windows 10 Mobile (W10M, сборка 15063+), созданный **без** использования системного WebView или движка Chakra. Использует собственный HTML-парсер, CSS-движок с селекторами/каскадом/flexbox, JavaScript-рантайм на базе [NiL.JS](https://github.com/nilproject/NiL.JS) и рендерер на XAML.

**v1.0 оптимизирован для [Nokia Design Archive](https://nokiadesignarchive.aalto.fi/)** — музейного сайта с 722+ записями, 33 коллекциями, 230 историями и 91 ключевым словом, документирующим дизайн-историю Nokia. MediaExplorer извлекает данные архива из JS-бандла сайта, отрисовывает их в виде интерактивных свайпаемых карточек с изображениями, чипами коллекций, тегами ключевых слов и ссылками на репозиторий Университета Аалто.

~40 файлов, ~25k+ строк кода. Релиз v1.0.

## Возможности

- **Собственный движок рендеринга** — HTML-парсер, CSS-каскад, flexbox, XAML-рендерер
- **JavaScript** — NiL.JS с поддержкой ES Modules (Vite bundles parse; D3v4/v5 support)
- **DevTools** — Console, DOM-инспектор, Network, Debug-лог
- **3 режима UI** — Скрытый (полоска), Полуоткрытый, Полный (стандартная панель)
- **3 режима рендеринга** — Полный (JS+CSS), Обогащённый (CSS без JS), Бедный (чистый текст)
- **Дисковый кэш** — Кеширование ресурсов с приоритетной очередью
- **MutationObserver** — Инкрементальный ре-рендер при изменениях DOM
- **Кнопка Snapshot** — Скриншот (обычный или длинный) в Pictures/MediaExplorer
- **Горячие клавиши** — Ctrl+L (фокус на URL), Ctrl+B (скрыть/показать панель)
- **Карточный режим для смартфонов** — Автоопределение узкого экрана (<600px), контент архива в виде свайпаемых карточек с детальным просмотром, каталогом категорий и маршрутизацией ссылок
- **Интеграция с Nokia Design Archive** — Извлечение __entries, __collections, __stories из JS-глобалов; отрисовка в виде интерактивных карточек с бейджами типа, чипами коллекций и ссылками на истории

## Статус

- **Релиз v1.0.** Фазы R (Retrench), S (Smartphone adaptivity), T (Text/Image/Link detail views) завершены.
- **SVG→XAML мост отброшен** — после 18+ сессий архитектурное несоответствие признано неисправимым на Win SDK 15063. Заменён текстово-карточным рендерингом для узких экранов.
- **Извлечение данных сохранено** — `__graphData` (755 узлов, 1647 связей), `__entries` (722), `__stories` (230), `__collections` (33) для будущего SkiaSharp-рендерера.

## Dev-секция (12 июня 2026)

### Ключевые решения
- **SVG→XAML удалён** — удвоение контента при скролле, архитектурная несовместимость, слишком тяжело для Lumia
- **Карточный режим** — прозрачная замена для узких экранов: свайпаемые карточки с деталями записей, каталог категорий, фильтрация по коллекциям
- **Маршрутизация ссылок** — внутренние URL записей (/entry/E0001) → карточный режим; внешние → системный браузер через Launcher
- **Извлечение данных** — сохранено для будущего Canvas2D-рендерера на SkiaSharp

### Ключевые файлы
`MainPage.xaml.cs` — карточный режим, навигация, маршрутизация
`Engine/BrowserApi.cs` — ExtractEntriesJson/ExtractCollectionsJson/ExtractStoriesJson
`AGENTS.md` — команды цикла автоматизации

Это самодельный браузерный движок — не для продакшена, не для замены Edge или Chrome. Он существует, чтобы доказать: для рендеринга веб-страницы не обязательно нужен Chromium.

## Тестирование

MediaExplorer лучше всего работает с Nokia Design Archive. Для общего тестирования веба рекомендуются эти сайты (по совместимости):

| Сайт | Тип | Примечания |
|------|-----|------------|
| [hackaday.com](https://hackaday.com) | Блог/ESP | Текст + картинки, лёгкий JS |
| [arstechnica.com](https://arstechnica.com) | Новости | Тяжёлый React, но есть контент |
| [wikipedia.org](https://wikipedia.org) | Wiki | Сложный HTML/CSS, хорошая нагрузка |
| [archive.org](https://archive.org) | Архив | Похожий дух на Nokia Design Archive |
| [musicbrainz.org](https://musicbrainz.org) | База данных | Текстовые данные, SPA |
| [openlibrary.org](https://openlibrary.org) | Книги | Картинки + текст, умеренный JS |
| [librivox.org](https://librivox.org) | Аудиокниги | Простой HTML, хорошая стабильность |
| [indiehackers.com](https://indiehackers.com) | Сообщество | React SPA, контентный |
| [producthunt.com](https://producthunt.com) | Стартапы | Тяжёлый SPA, хорошая нагрузка |
| [news.ycombinator.com](https://news.ycombinator.com) | Минимализм | Почти без JS, базовый тест |

**Совет:** Начните с лайтвейт-сайтов (Hackaday, Wikipedia, LibriVox) на Lumia 950. Тяжёлые SPA (Reddit, Product Hunt) полезны как стресс-тест, но могут сломаться на NiL.JS.

## Известные проблемы

- Исходник на 100% «нейро-слоп» от ИИ (кроме оригинального кода UDAIE-A WebView)
- Не тестировался ни на одном W10M-устройстве
- Белый экран на некоторых сайтах (dzen.ru, ya.ru)
- Ошибки runtime ES Modules всё ещё исправляются
- Приватные поля (`#name`) не поддерживаются
- SVG→XAML рендеринг отброшен — сложные графы/таймлайны отложены до SkiaSharp (v1.1+)
